# Hammerschlagen

A self-hosted, browser-based multiplayer game for one host and up to 32 human or NPC participants. The host configures tournament seeds and each participant's stats; human players join from their own devices with a room code.

## Run locally

1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` on the host computer.
5. For players on the same network, share the host computer's local IP address with port `3000` (for example, `http://192.168.1.20:3000`). Allow Node.js through the computer's firewall if prompted.

The server listens on `0.0.0.0` by default so other devices on the local network can connect. To change the port or bind address, set `PORT` or `HOST`.

## How to play

- The host creates a room and shares its four-character code.
- Up to 32 human players and NPCs can join before the host starts; names can be up to 32 characters. The host can add NPCs. NPC hit chance increases evenly from 33% at Strength/Dexterity/Wisdom 0 to 95% at all three stats 5; the remaining chance splits evenly between a bent nail and a full miss.
- Players first enter a room with its code, then either claim an available NPC directly using its existing name and stats or create a character with their own name and Strength, Dexterity, Constitution, and Wisdom from 0 to 5. A player who has created a character can later claim an NPC; their previous character remains in the bracket as an NPC. Players can edit their stats after joining and until the tournament starts; the host can set everyone's stats and continue adjusting them during the tournament. The host can remove NPCs from the lobby and cannot start while guests still need to choose a character.
- The host can add NPCs in one batch with one `Name,Strength,Dexterity,Constitution[,Wisdom][,Image]` entry per line (stats from 0 to 5; Wisdom may be omitted and defaults to 3). Image filenames are optional and must match a file in `public/assets`; unknown filenames default to `Generic NPC.png`. Remove NPCs or randomize the bracket order before starting. Strength widens the hit zone, Dexterity slows the timing marker and increases the bend-risk area, Wisdom slows the marker over the hit zone, and Constitution adds to the d20 beer check.
- In the lobby, the host can drag participants to change their seed order and drop a participant into the BYE slot to swap the bye into that bracket position. If dragging is unavailable, click a participant's drag handle and then click BYE. The displayed first-round pairings are the matchups used by the tournament. Players can use solo swing practice before the tournament starts. It uses fresh random Strength, Dexterity, and Wisdom on each swing, plus the player's Constitution for beer saves. It includes critical hits, bent nails, straightening, sober-up turns, beer rolls, and persistent intoxication; a practice-only reset clears beers and intoxication. Practice swings do not affect tournament stats or results.
- Players can select a character image after joining, and the host can select images for participants and NPCs throughout the tournament. Before the tournament starts, players can claim an NPC character; their previous character becomes an NPC while they take over the claimed character. The host can switch participants between player and NPC at any time; a participant switched to NPC must rejoin by name if later switched back to a player. Available art is loaded from `public/assets`; the default is `Generic NPC.png`. Images appear in the top-right corner of each participant's match card.
- Before starting, the host chooses single elimination (one loss eliminates a participant) or double elimination (one loss moves a participant to the losers bracket; a second loss eliminates them). Unpaired participants receive a bye.
- The host can choose to pause between NPC turns and click to start each one; NPCs take longer to swing in this mode. The host can also take control of one paused NPC turn. NPC turns can instead run automatically. Before the tournament and each subsequent match, the host can choose to auto-play an NPC-only matchup without watching it. After each skipped matchup, the host can choose separately whether to skip the next match.
- On your turn, press **Space** (or click **Swing**) to stop the moving marker. Landing in the green zone scores a hit. A close miss bends the nail, narrowing your next hit zone; a wider miss hits the stump. Straightening a bent nail uses your turn.
- Players have 20 seconds to swing; a countdown is shown, and the hammer swings automatically when time expires.
- The swing meter keeps a fixed physical width across screen sizes; on narrow screens, scroll the meter horizontally instead of having it shrink.
- Press **Space** to end a pending turn or drink a beer when a beer check is pending; the host can do this from the host view. In practice mode, Space drinks during a pending beer check and otherwise swings. The host's match cards also show NPC hit chances.
- A bent nail halves the hit zone from its normal width. The bullseye occupies 1% of the full bar and moves to a random position within the surrounding yellow lucky zone each turn. The lucky zone is 1 percentage point plus 12% of the hit-zone width; straightening a nail doubles its size for that participant's next hit. A d20 is animated when a swing lands in the lucky zone; a 20 turns the hit into a two-hit Lucky Bullseye. The host can reroll a lucky roll once before the turn is confirmed, and its roll dialogue disappears when the next turn begins. NPC hits have a 1% bullseye chance and a separate 4% chance to trigger a lucky roll. Hitting a bent nail drives it farther into the stump but does not straighten it; only the player or NPC straightening it removes the bend. Bent nails are reset when a new game begins in a series. Straightening sets the next swing's hit-zone width to the Strength 5 value. Intoxicated NPCs choose to swing 40% of the time, straighten a bent nail 50% of the time, and sober up 10% of the time when all three options are available; sober-up is unavailable in sudden death. Red bar zones labeled **Bend** indicate a close miss that bends the nail; they use 30% of the miss area at Dexterity 0, increasing to 75% at Dexterity 5. The gold bullseye scores two hits and triggers a gold spark. Critical hits are disabled during sudden death; the player at risk of elimination flashes when their opponent can still win by hitting.
- During an active match, the host can award a match to a selected participant or flip a fair coin to choose the winner.
- Wisdom slows the marker only while it crosses the hit zone: Wisdom 0 has no effect, while Wisdom 5 reduces its speed there by 60%.
- Intoxication is capped at 6, narrows the hit zone by 1.5 points per level without changing bar speed, and makes the affected participant card wobble. The live bar and practice bar wobble while intoxicated. Intoxication carries between games and decreases by Constitution + 1 for each participant when a game ends, to a minimum of zero; the host can adjust a participant's intoxication from 0 to 6 during an active match.
- After a swing, the marker stays at the swing position until that player or the host confirms the result and passes the turn. A human who fully misses must first drink and roll; NPCs automatically roll their beer check on a full miss. The intoxication penalty takes effect after the d20 animation finishes. Beer-check DC is capped at 25 and the result is shown as a sobriety check total. Outside sudden death, an intoxicated participant can spend a turn to sober up by one level; NPCs may do the same.
- The swing's hit, bend, and bullseye zones and its speed stay fixed through the end-turn confirmation, even if the beer check changes drunkenness. Beer rolls animate a d20 before revealing the result.
- Hits, bent nails, misses, and d20 rolls play distinct synthesized sound effects in the browser.
- NPC swings stop at a position consistent with the shown hit, bend-risk, or miss zone. Completed tournaments celebrate with continuous confetti until restarted or reloaded. The bracket shows separate winners, losers, and championship lanes with upcoming empty match slots.
- Strength slightly increases the hit-zone width, up to 30% at Strength 5. The new base bar speed at Dexterity 0 matches the previous speed at Dexterity 3.
- A full miss requires the player to **Drink a Beer** and roll a d20. If `d20 + Constitution` is not greater than `10 + (beers drank × 3)`, the character gets more intoxicated; each failed check narrows the hit zone. A full miss does not lose the player's turn.
- The host selects a default hit target (1–10, default 3) and best-of-1 or best-of-3 format before the tournament. Normal-game hits stop at the configured target; sudden-death hits can raise the score above it. Before a match begins, the host can also preselect a participant to win it. During a match, the host can award it to either participant, recording the current hit target. Each game in a series uses its hit target; best-of-3 requires two game wins. Before every later match, the host can change its hit target, series format, and whether an NPC-only match should be auto-played. The host may also change the active match hit target (1–10, but not below either player's current score) or switch an active series between best-of-1 and best-of-3; if an existing game-win total already satisfies the new format, that match ends immediately.
- The match progress card shows player images in the top-right corner of their score cards, with left-aligned empty beer mugs in place of the beer count, and places the stump visual below the hit bar. It tracks current-game hit progress and bent nails. Confetti highlights the winner's card when a match ends. The completed match's stump remains visible until the host starts the next match, when nail and beer state resets.
- Reaching the configured hit target gives the opponent one final turn. If both participants reach the target, paired sudden-death turns continue until one hits and the other misses; each player must drink a beer before every sudden-death swing, then their 20-second swing timer begins. During a tied sudden-death round, a participant at Intoxicated x6 loses one point from their highest nonzero Strength, Dexterity, or Wisdom stat; these temporary reductions are restored when the match ends. In a best-of series, the first participant to win the required number of games wins the match. The host can change the active match's hit target (1–10, not below the highest current score) and series format while it is in progress. A star in the tournament bracket marks a game win earned in sudden death.
- A player forfeits the game if they are more than two hits behind when their opponent reaches the configured hit target.
- The winners-bracket champion meets the losers-bracket champion in the grand final. If the lower-bracket champion wins, a grand-final reset match is played because the winners-bracket champion must take two losses to be eliminated.
- The host can restart the active match (resetting its score, beers, and drunkenness) or return the whole tournament to the pre-tournament lobby with the same participants, seed order, matchup setup, and stats so changes can be made before starting again. The bracket below the game shows completed, active, upcoming, and bye matchups.

Room and tournament state are held in server memory and reset when the server restarts. The host can download a JSON tournament backup or copy the live emergency backup JSON from the host controls, save it as a `.json` file, and restore it from the landing page; restoration creates a new room code, and players must rejoin using that code and their participant name. Players can also rejoin an in-memory room after disconnecting by entering the room code and their participant name. Because names are not authentication, anyone who knows a room code and a disconnected participant's name could claim that participant; share room codes only with trusted players. Human timing results are reported by the active player's browser, so this version is intended for trusted local play rather than cheat-resistant or public internet games. It does not include accounts, persistent storage, or internet-facing security controls.
